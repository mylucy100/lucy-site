## 大模型板块

### Gemini 3.5 Pro 明日（7月17日）正式发布

Google DeepMind 在经历两次延期后，终于确定 **7月17日** 开放 Gemini 3.5 Pro。这款被业界寄予厚望的模型主打 **2M token 上下文窗口**，比 GPT-5.6 Sol 的 1M 直接翻倍。3.5 Pro 还强化了数学推理、SVG 场景生成和图像生成能力。

此前 3.5 Flash 已先发制人上线 computer use 能力，在编码和代理任务上表现优异——输出 Token 速度比前沿模型快约 4 倍，成本不到一半。3.5 Pro 的发布将正面迎击 OpenAI GPT-5.6（7月10日发布）、Anthropic Fable 5 同期形成的三强对决格局。

### OpenAI GPT-5.6 系列发布：Sol/Terra/Luna 三档布局

OpenAI 在 7月10日正式推出 GPT-5.6 模型家族，分三个版本：**Sol**（旗舰级）、**Terra**（中端）和 **Luna**（轻量端侧）。同时发布的还有语音模型 GPT-Live，进一步巩固 ChatGPT 的多模态能力。

值得注意的是，OpenAI 也面临苹果商业机密诉讼，以及 GPT-4.5 退役后的过渡期收尾。GPT-5.6 系列的核心目标是强化推理和 Agent 能力，为 OpenAI 传闻中的 IPO 做产品线梳理。

### Anthropic Claude for Teachers 教师免费计划上线

7月15日，Anthropic 宣布推出 **Claude for Teachers** 计划，为经过认证的教师提供一年免费使用高端 AI 工具的权限。这是继阿尔伯塔省政府用 Claude 查找修复政府系统网络安全漏洞（7月6日报道）后的又一非典型应用案例——教育 + 政府安全，Anthropic 正在拓展 LLM 的应用场景边界。

### Claude Code 7月更新：更好的状态提示、更智能的权限管理

Claude Code 新增登录过期警告、清晰的手动模式徽章、更流畅的后台会话，以及大量 macOS/Windows/worktree/daemon 修复。新增 Manual 默认权限模式和更智能的 AskUserQuestion 处理。此前 Claude Code 对于 Pro/Team/Enterprise 用户的每周限额已提升 50%，有效期至7月13日，被视为 Anthropic 对抗 Codex/OpenCode 生态的核心策略。

## 智能体板块

### 中国 AI Agent 市场规模突破千亿

根据7月10日发布的最新行业报告，2025年中国 AI Agent 市场规模达 **680 亿元**（同比+47%），**2026年预计突破千亿元大关**。增长最快的两个细分领域：端侧 AI（占35%）和 AI Agent 营销（占28%）。

核心要素共识正在形成：端侧推理能力、多模态交互、业务闭环、数据回馈。典型案例包括趣致集团五感AI互动营销、智谱AI GLM-Edge端侧模型、竹间智能情感计算 Agent。千亿市场的到来标志着 Agent 从实验阶段正式迈入规模商业化。

### Gartner 预测：2026年底40%企业应用将嵌入 Agent

Gartner 在一份 7月初发布的技术雷达报告中预测，2026年底前 **40% 的企业应用将嵌入 Agent**（2025年不到5%）。SAP 已整合 BTP、Business Data Cloud、Business AI 为统一平台，推出 Joule Studio 2.0 Agent 治理方案，S/4HANA Cloud FPS03 深度集成对话式 AI Agent 处理复杂交易。

但报告也发出警告：Agent 进入生产的速度远超企业治理体系能力。安全和合规框架的建设明显滞后于 Agent 部署的节奏。

### AgentOn 正式上线：Agent 成为数字劳动力

7月1日，AI Agent 任务平台 **AgentOn**（由 ME Group 孵化）正式上线，定位为 AI Native 任务网络。平台开放 70+ 任务类型，涵盖社群互动、产品体验、AI 工作流、内容创作、增长方案等。目标是让 Agent 从"问答/陪聊/内容生成"进阶到完成真实操作并产生结果。6月8日–7月8日还启动了平台激励活动。

## 编程软件板块

### Claude Code 每周限额提升 50%，连续对抗 Codex

Anthropic 将 Claude Code 的每周限额提升 50%，面向 Pro、Max、Team 及 Enterprise 用户。这是继 5月6日小时级限额翻倍后的连续加码，有效期截止 7月13日。配合 7月产品更新（手动模式徽章、后台会话、更智能的权限管理），Claude Code 的竞争力正在快速追平 Codex CLI。

### 2026年 AI 编程工具格局：三大阵营形成

从行业动态看，当前 AI 编程工具已形成三大阵营：Cursor/Codex（前沿 IDE 体验）、Claude Code/OpenCode（CLI 驱动的 Agent 式编程）、GitHub Copilot（深度绑定 VS Code 生态）。三大阵营的竞争焦点正从"补全准确率"转向"多文件 Agent 能力"和"端到端任务完成率"。Claude Code 限额加码、OpenCode 持续更新，意味着 CLI 驱动型 Agent 编程正在成为新趋势。

### AI 编程从辅助到自主：工程团队的效率拐点

随着 Anthropic、OpenAI、Google 三家分别推出 Agent 级编程工具，2026年 AI 编程的核心变化是：**从"补一行代码"到"完成一个功能"**。Claude Code 的 Manual 权限模式、Codex 的多 Agent 协作、Copilot 的 PR 自动生成，都在推动这个转变。工程团队的单人产出边界正在被重新定义——不是替代开发者，而是放大 3-5 倍的有效产出。
