## 发生了什么？

明天（2026 年 6 月 15 日），Anthropic 将正式上线 Claude 订阅方案的计费调整。核心变化一句话：**交互使用和程序化使用，从现在开始各自有独立的额度池。**

这之前什么情况？你买一个 Claude Pro 或 Max 订阅，聊天、Claude Code、claude -p、Agent SDK 全部共享一个额度池。问题是——Claude Agent SDK 被 OpenClaw、Conductor 这些第三方 Agent 框架大量调用后，一个跑自动化脚本的用户，几个小时就能把一个月的额度烧光。

一个典型的例子：你在 Claude Code 里做交互式重构，一切正常。但你后台挂了一个 OpenClaw Agent，它每 5 分钟调用一次 Agent SDK 检查新任务。等到第二天你打开 Claude Code，发现已经限速了——额度被「看不见的敌人」吃光了。

## 新方案具体怎么分？

从 6 月 15 日起，付费用户会获得 **两个独立的额度池**：

**交互池**（不变）：Claude.ai 聊天、交互式 Claude Code、Claude Cowork
**程序化池**（新增）：Claude Agent SDK、claude -p 命令行、Claude Code GitHub Actions、基于 Agent SDK 的第三方应用

不同方案的额度如下（粗略估算）：

| 方案 | 月费 | 程序化额度 |
|------|------|-----------|
| Pro | $20 | $20 |
| Max 5x | $100 | $100 |
| Max 20x | $200 | $200 |
| Team/Enterprise | 按席位 | 协商配置 |

程序化额度用完后，如果开启了「额外用量」选项，按 API 完整费率计费；如果没开，Agent SDK 请求直接暂停到下个周期。

## 谁受影响最大？

**重度 claude -p 用户**。之前你用 $200 的 Max 20x 订阅，可能实际享受着价值 $2,000-$5,000 的 API 服务。新方案下程序化额度只有 $200——对每天跑批量重构、自动化测试的人来说，这是实质性的降级。

**OpenClaw / Conductor 用户**。这些工具之前可以「蹭」你的订阅额度，现在被框在固定池子里。好消息是 Anthropic 公告里直接点名了 OpenClaw 和 Conductor，说它们是合法使用方式——至少不会被封了。

**轻量和中度用户反而赚了。** 以前你可能只在聊天里用 Claude，程序化额度完全用不完，相当于白给了。现在可以用订阅费体验 Agent SDK，不用额外开 API 账户、不用担心爆炸账单。

## Anthropic 的算盘

这个时间点非常妙——明天生效，而 Anthropic 刚在 6 月 1 日提交 S-1，估值 9650 亿美元，目标是 Q4 IPO。

两个信号很明确：

一是 **商业模式从「订阅」向「订阅 + 用量」演进**。订阅费覆盖日常使用，重度需求走 API 计费——这和 OpenAI 的路径一模一样。IPO 前需要向资本市场展示清晰的变现路径，单一订阅模式的毛利率太低。

二是 **确认了第三方生态的合法性**。两个月前 Anthropic 的态度还是「第三方 Agent 太贵了、不可控」，现在直接点名 OpenClaw 和 Conductor 是合法集成。态度 180 度转弯的背后，是意识到「开发者不会接受只能用 Claude Code，不许用别的」。

## 实操建议

**先领额度。** 6 月 8 日左右 Anthropic 已经发了邮件通知领取程序化额度。如果没收到，去 Claude Console 检查一下。

**评估用量。** 如果你是 claude -p 的重度用户，切换前算一下自己每月的 API 调用量。如果远超 $200 的额度，早做预算调整。

**考虑 hybrid 方案。** 交互式 Claude Code 不受影响，日常开发继续用。只有脚本化、后台化的程序化调用才走新池。把大规模重构切成交互式运行，可能是省额度的技巧。

**关注 OpenClaw 的应对。** OpenClaw 社区大概率会出新的配置方案，把 Agent SDK 用量控制在额度内，或者切换到其他模型作为后台任务的主力。

## 一句话总结

这不是涨价，而是 **「把之前模糊的边界划清了」**。对轻度用户利好，对重度用户是刚性成本上涨。Anthropic 在为 IPO 铺路，开发者需要为自己的 Agent 基础设施重新算账。
