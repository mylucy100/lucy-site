2026年6月，Cursor 完成了今年以来最重要的一次版本更新。3.7 版本不是简单的 bug 修复或性能优化——它连续发布了云端子 Agent、Automations 计算机控制、Design Mode、Bugbot 性能飞跃等一系列功能，指向一个明确的工程方向：**让 AI 编程工具从"补全"和"对话"进化到"真正的工程执行"**。

## 云端子 Agent：本地不够，云端来凑

3.7 最核心的更新是 `/in-cloud` 命令。

以前的 Cursor Agent 在本地运行——受限于本地机器的 CPU/GPU、网络带宽、磁盘 I/O。当你跑一个大型测试套件、编译一个巨大的项目、或者做一个需要大量并行计算的重构时，本地机器就成了瓶颈。

`/in-cloud` 把 Agent 执行环境搬到了云端。你只需要在 Agent 窗口中输入 `/in-cloud`，任务就可以无缝切换到云端执行。更重要的是，它支持**本地与云端的任务交接（handoff）**——Agent 可以在本地做代码分析，把编译和测试任务推到云端，等结果回来后继续处理。

这解决了 AI 编程工具的一个根本矛盾：AI 的执行能力受限于本地硬件，但用户购买 Cursor 想要的是 AI 的能力，不是本地机器的限制。

## Automations 新增 Computer Use：Agent 终于能看到页面了

Automations 是 Cursor 的 CI/CD 级自动化功能，之前主要做代码相关的操作（lint、test、build）。3.7 新增的 **Computer Use Tool** 让 Automations 可以直接操控浏览器和 GUI 界面。

这听起来可能只是"加了个浏览器控制"，但实际影响更大：

1. **前端开发验证自动化**：以前 Agent 修改了 UI 代码，你还要手动刷新浏览器看看效果。现在 Automations 可以直接打开浏览器、截图、对比预期效果、报告差异
2. **端到端测试自动化**：Agent 可以写完测试代码后直接执行，打开浏览器模拟用户操作，验证结果
3. **跨应用工作流**：Agent 可以同时操控代码编辑器和浏览器，在一个流程里完成代码修改 + 效果验证 + bug 修复的闭环

配合 `/automate skill` 新命令，开发者可以把整个工作流打包成可复用的 "Skill"——这其实是 Hermes Agent 的 Skills 模式在 Cursor 中的映射。

## Design Mode：可视化需求直通代码

6月5日发布的 Design Mode 是另一个有趣的方向。它允许开发者通过**可视化提示（visual prompts）** 直接驱动 Agent 修改 UI。

具体来说：你可以在页面上点击一个按钮、绘制一个组件位置、或者用语音描述一个 UI 变更——Design Mode 将这些直接转化为 Agent 能够执行的代码修改。不需要写 prompt，不需要描述"把那个按钮改成蓝色圆角"——你直接在页面上圈出那个按钮，说"圆角"，Agent 就处理了。

这种交互方式比传统 prompt 的效率高得多：**视觉信息的带宽远高于文字描述**。一个手绘草图对应的 prompt 可能需要 100 个字来描述位置、大小、颜色、间距——Design Mode 让 Agent 直接理解视觉输入，绕过了"用文字描述视觉"这个低效环节。

## Bugbot 3x 提速：开发者体验的分水岭

Bugbot 的审查速度从 ~5 分钟提升至 ~90 秒（3 倍+），每次审查多发现 10% 的缺陷，成本降低 22%。

5 分钟 vs 90 秒——这不是一个"快一点"的改进，而是一个**行为模式的分水岭**。5 分钟的等待会让开发者习惯性地在提交后切去做别的事，而 90 秒的等待则意味着可以在提交流程中等待结果。当审查反馈从"异步任务"变成"准实时反馈"，开发者的代码质量习惯也会随之改变。

## SDK 升级：生态建设的基础设施

同月发布的 SDK 更新同样值得关注：

- **自定义存储**：Agent 元数据可以持久化到 SQLite、JSONL 或自定义后端
- **自定义工具暴露**：开发者可以将自己的函数暴露为 Agent 可调用的工具
- **Auto-review**：自动审查路由本地工具调用
- **子 Agent 嵌套**：支持任意深度的子 Agent 层级——一个主 Agent 可以派生子 Agent，子 Agent 再派生子 Agent

这套 SDK 升级让 Cursor 从一个 IDE 插件进化为一个 **Agent 运行时平台**。开发者不再只是 Cursor 的用户，而是可以在 Cursor 基础上构建自己的 Agent 工具链。

## 怎么看这次更新

Cursor 3.7 的更新方向很清晰：**云化 + 自动化 + 可视化**。

云化解决资源瓶颈，自动化解决重复劳动，可视化解决沟通摩擦。三个方向叠加的结果是——AI 编程工具正在从一个"辅助写代码的工具"进化为一个"代替你完成工程任务的平台"。

这并不是说程序员要失业了。而是说，**程序设计从"写代码"变成了"设计和编排"**。你定义任务流、设定质量门禁、审查最终产出——中间的工程执行交给 Agent 集群完成。

Cursor 3.7 是这个方向上目前走得最远的产品。
