## 大模型板块

### Kimi Work 公测：月之暗面杀入本地 Agent 战场

6月4日，月之暗面正式推出 **Kimi Work**——首款面向知识工作者的通用型本地 Agent。绑定 Kimi 最新测试版 Mac/Windows 客户端，用一句话描述目标，Kimi Work 就能拆解任务、并行执行、调浏览器、创建文件夹、交付文档/表格/PPT。

这不是另一个聊天窗口。这是 Agent 直接跑在你的电脑上，读写你的本地文件。长江证券认为 AI 应用商业化拐点已至——参考美国路径，资本开支领先商业化一年，2026年就是那个节点。

与此同时，Kimi 估值在 6月8日传出新融资消息，**pre-money 估值已达 300 亿美元**。从 2025 年底的 43 亿到现在的 300 亿，半年 7 倍。K2.6 模型（4月发布）的 Agent 集群支持 300 个子 Agent 并行协作，这波底牌确实硬。

### DeepSeek V4.1 预告 + Harness Agent 团队

DeepSeek 计划在 6 月推出 **V4.1 迭代版**，同时组建了名为 Harness 的 Agent 团队——核心理念是 "Model + Harness = Agent"，模型和产品协同进化。V4 发布 140 天后终于要有新动作了。1.6T 参数、1M 上下文、MIT 开源，V4.1 会加什么？大概率是 Agent 能力和推理效率的优化。

### GPT-5.5 Instant 最新更新

OpenAI 在 5月28日更新了 GPT-5.5 Instant，改进响应风格和质量。同时 GPT-4.5 确定在 6月27日退役。GPT-5.5 目前 84.9% GDPval 知识工作者基准，Sam Altman 确认今年不会有 GPT-6。

## 智能体板块

### Meta Business Agent 全球上线：每个企业都有 AI 客服了

6月3日伦敦 Conversations 大会，Meta 正式推出 **Meta Business Agent**，同时在 WhatsApp、Messenger、Instagram 上线。一分钟配置，支持 100+ 种语言，24/7 自动回复客户。

核心数据：每天超过 10 亿条企业与客户的对话在 Meta 旗下应用进行。100 万+ 企业已经在用。起步免费，后续提供付费订阅方案。

同时发布的 **Meta Business Agent Platform** 允许企业接入 Shopify、Zendesk 等数百个系统——Agent 不止聊天，还能下单、查库存、改订单。对小商家来说，这就是雇了一个 24/7 不睡觉的客服团队。

### Microsoft Build 2026：Agent 优先的操作系统

6月2-3日，微软 Build 2026 核心只有一个主题：**Agent-First**。几个值得关注的产品：

- **Microsoft Scout**：基于 OpenClaw + Work IQ 的"始终在线"个人工作 Agent，今天给 Frontier 客户
- **Work IQ API**：M365 数据（邮件、会议、文档）开放给任何 Agent，6月16日 GA
- **ASSERT + Agent Control Specification**：开源的 Agent 安全评估框架
- **MAI-Thinking-1**：35B 激活参数、256K 上下文，SWE-Bench Pro 持平 Opus 4.6

翻译一下：微软在把自己所有的企业数据变成 Agent 的上下文。你 Agent 能直接读我的邮件和文档？那你就不需要别的 RAG 了。

### Agent 安全成为新战场

6月第一周，Agent 安全密集爆发：
- **Zscaler** 推出零信任 Agent 安全方案
- **Cisco** 发布 AgenticOps 运营平台
- **Microsoft** 开源 ASSERT + 发布 Agent Control Specification
- **Asana** 收购 StackAI（无代码 Agent 构建）
- **Palo Alto Networks** 收购 Portkey（AI 网关）

买方在买什么？安全执行层——不是模型多聪明，是 Agent 在企业系统里跑的时候能不能被控制、审计、停掉。

## 编程软件板块

### GitHub Copilot 正式切换按量计费

6月1日起，所有 Copilot 套餐切换到 **GitHub AI Credits** 计费模式。按 token 消耗（输入+输出+缓存）而不是按请求数。

这意味着写两行代码和跑一个小时的自主编程任务，价格终于能反映了。社区反应两极分化——重度用户可能涨价，轻度用户可能更便宜。关键动作：立即设置用户级预算上限和告警。

### Claude Code Managed Agents：终端 Agent 的下一步

Anthropic 在 Code with Claude London 上发布 **Claude Managed Agents**——团队可以部署"24/7 在线的编码 Agent"，还有 **Claude Agent SDK** 开放给外部开发者。

核心看点是 **Dreams**（研究预览）：Agent 自主做规划-执行-验证-迭代。编程已经从写代码进化到设计 Agent 来做编程。

### Niteshift：跨模型路由平台

6月11日刚上线的 Niteshift，定位是 **coding-agent 平台**，在不同模型之间路由任务——Claude 做规划、GPT-5.5 做执行、Gemini 做验证。反映了 2026 下半年的趋势：不是选一个模型，是搭建模型编排层。

### AI 编程工具生态速览

- **Trae** 国内综合评分第一（9.5/10），累计用户 600 万+
- **Cursor** 估值冲击 500 亿美元，年收入 20 亿美元
- **Claude Code** 评分 9.4/10，终端 Agent 体验天花板
- **Qoder** 新兴平台，免费计划无限代码补全
- 趋势：从代码补全 → 端到端功能开发 → 自主 Agent 执行
