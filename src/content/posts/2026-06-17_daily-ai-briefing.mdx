## 大模型板块

### OpenAI GPT-5.6 预计6月发布，S-1秘密提交冲刺IPO

OpenAI 向 SEC 秘密提交了 S-1 注册声明草案，估值 8520 亿美元，高盛/大摩/小摩联合承销。研究负责人透露 GPT-5.6 可能在 6 月发布，正面迎击 Anthropic Fable 5。同时 OpenAI 6 月密集行动：收购 AI 研究公司 Ona、与 Oracle 深化合作、推出新 Academy 课程。

值得注意的是，OpenAI 同步更新了 Agents SDK，引入了沙盒执行环境和模型原生运行框架（harness），支持 gpt-5.4，并与 Temporal 合作实现持久化执行。

### Anthropic 估值9650亿超越OpenAI，AI IPO大年成型

Anthropic 和三方（OpenAI、SpaceX）同步冲刺 IPO。Fable 5 / Mythos 5 发布后 SWE-Bench Pro 达 80.3%，断层领先 GPT-5.5（仅 58.6%）。6 月 15 日起执行的 Claude 付费计划将交互使用与程序化调用切割为独立额度池，防止"低价吃高量"——这对重度 API 用户影响显著。

### DeepSeek 计划推 V4.1，月之暗面 K2.7 Code 开源

DeepSeek 计划 6 月推出 V4.1 更新，提高模型发布频率。月之暗面新一轮 20 亿美元融资（投前估值 300 亿美元）启动，同时开源 K2.7 Code 编程模型，K2.6 已支持 300 个 Agent 并行运行。华为 HDC 2026 同期开幕，展示了盘古大模型 5.0 的行业应用。

## 智能体板块

### Coze 3.0 上线：多人多 Agent 协作

字节跳动扣子 6 月 1 日发布 Coze 3.0，支持多人多 Agent 协作、接入 Claude Code / Codex CLI / OpenClaw 等外部平台，具备自媒体、法律、金融等专家技能模板。AI Agent 市场"三分天下"格局已定：消费生态型（Coze / 腾讯元器 / 百度文心）、企业底座型（金智维 Ki-AgentS）、前沿探索型（Manus / Google Astra / OpenAI Operator）。

### AI 安全成 Agent 落地的核心瓶颈

CB Insights 最新报告指出语音 AI 崛起、并购潮、agentic 支付商业模式将成为 2026 主线。但与此同时，Agentic AI 规模化落地后焦点正从"能否用起来"转向"能否用得安全"。"驾驭工程"（Steering Engineering）理念升温，强调通过约束、权限边界和行为控制为智能体设"安全护栏"。

## 编程软件板块

### GitHub Copilot 6 月起按 Token 计费

6 月 1 日起 GitHub Copilot 正式转向按使用量计费（Token / 积分制），固定订阅价模式结束。Pro 仍为 $10/月但实际成本因用量可能上涨 2-3 倍。更重磅的是：Microsoft 计划在 6 月 30 日前终止内部大部分 Claude Code 许可，全面转向自研 Copilot CLI。

### Trae 登顶 Q2 编程工具榜，Cursor 3 紧随其后

2026 Q2 AI 编程工具综合排名：Trae（字节，9.5/10）> Cursor（8.7）> Claude Code（8.5）> GitHub Copilot（8.1）= Windsurf（8.1）。Trae 国内版正式发布，搭载豆包 1.5-pro 模型并支持 DeepSeek R1 & V3 切换，累计注册用户突破 600 万，代码生成准确率 98%。

另一个值得关注的信号是：AI 生成代码的漏洞率是人工代码的 2.74 倍，长期维护成本可能增加 300%——效率提升不能忽视质量风险。
