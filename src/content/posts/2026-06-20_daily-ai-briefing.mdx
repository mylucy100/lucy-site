## 大模型板块

### OpenAI 向 SEC 提交 IPO S-1 草案

OpenAI 于6月8日向美国证券交易委员会（SEC）保密提交了 S-1 注册声明草案，正式启动上市进程。此前该公司在3月完成了1220亿美元融资，估值8520亿美元。CEO Sam Altman 倾向"2026年Q4最快上市"，CFO 则认为条件尚不完全成熟。这是 OpenAI 从私募走向公开市场的里程碑动作，意味着其治理结构将面临更严格的监管审查。

同在6月，OpenAI 还收购了 AI 初创公司 Ona，推出 OpenAI Partner Network 拓展企业生态，并与 Oracle 达成合作——通过 Oracle 云承诺即可访问 OpenAI 模型和 Codex。

### Anthropic 白宫禁令：Fable 5 安全护栏引发政府决裂

6月的最大政治化新闻来自 Anthropic。特朗普政府下令禁止联邦机构使用 Anthropic 产品，起因是 Anthropic 拒绝白宫要求其移除 AI 安全护栏、向军方无限制开放 AI 工具。Anthropic 在声明中强调了负责任的 AI 部署原则，但代价是失去联邦政府客户。

Claude Fable 5 于6月9日发布后，SWE-Bench Pro 编程基准达 80.3%（GPT-5.5 仅 58.6%），SWE-Bench Verified 达 95%。Anthropic 估值达 9650 亿美元，首次超越 OpenAI，冲刺秋季 IPO。

### DeepSeek V4.1 计划6月发布

据 OSCHINA 和 Reddit 社区消息，DeepSeek 计划在6月发布 V4 的迭代版本 V4.1。V4 Pro（1.6T参数/49B激活 MoE，1M token上下文）于4月24日发布后，社区普遍反馈"训练不足、潜力未充分释放"。V4.1 将作为性能优化版修补这个短板——类似 V3→V3.2 的迭代路径。Fortune 6月16日报道了 DeepSeek 在 Anthropic 封杀开源背景下的全球化扩张战略。

### 通义千问发布 Qwen-Robot Suite（6月15日）

阿里 Qwen 团队发布 Qwen-Robot Suite，一套面向物理世界智能（Physical World Intelligence）的基础模型套件，标志着 Qwen 正式进入机器人和具身智能赛道。同时，Qwen3.7 付费版本按计划于6月全量开放，Qwen3.7-Max-Preview 综合评分 1284 分（超越 GPT-5.5 的 1215 分），推理成本仅为 GPT-5.5 的 1/25。

## 智能体板块

### AI Agent 商业闭环三条路径同时突破

6月18日发布的行业全景分析显示，AI Agent 正从技术验证走向商业闭环，四条路径同时突破：

1. **支付协议层**：微信、支付宝、京东、银联在48小时内集体入局 AI 支付，Agent 终于能替用户完成真金白银的交易
2. **操作系统层**：Android 17 将 Gemini 嵌入 OS 底层（6月16日推送），微软 Solara 构建 AI Agent 专用操作系统
3. **基础设施层**：MCP 协议安装量达 9700 万，DeepSeek V4.1 原生支持 MCP，GPT-5.6 达 150 万 token 上下文
4. **框架层**：2026年全球 AI Agent 市场规模达 286 亿美元，80% 组织已看到可衡量的投资回报

### Kimi 月之暗面估值飙至 300 亿美元

月之暗面于6月8日开启新一轮融资，投前估值达 300 亿美元——从 2025 年末的 43 亿美元在半年内翻了近 7 倍。ARR 在4月突破 2 亿美元。Kimi Work（本地通用 Agent）于6月3日公测，支持自然语言拆解任务、并行执行、交付文档/表格/PPT。市场已传出筹备港股 IPO 的消息。

### Hermes Agent GitHub 星标破 9.56 万

据6月发布的 AI Agent 深度研究报告，Hermes Agent 在发布后 7 周内 GitHub 星标突破 9.56 万，成为增速最快的 Agent 项目之一。OpenClaw 以 21.6 万星标领跑，AutoGPT 17 万紧随其后。

## 编程软件板块

### Cursor 3.7：云端子 Agent + Automations 计算机控制

Cursor 在6月17日发布 3.7 版本，核心更新：

- **云端子 Agent（/in-cloud）**：Agent 窗口中可启动云端子 Agent，实现本地与云端的任务交接
- **Automations 新增 Computer Use Tool**：允许自动化脚本直接操控浏览器/GUI 进行操作
- **Bugbot 审查速度提升 3 倍**：从 ~5 分钟降至 ~90 秒，每次审查多发现 10% 缺陷，成本降低 22%
- **Design Mode**：6月5日发布，通过点击/绘制/语音描述 UI 变更直接驱动 Agent 更新界面
- **SDK 更新**：支持自定义存储（SQLite/JSONL）、自定义工具暴露、Auto-review 和嵌套子 Agent

### Trae / Codex / Claude Code 动态

- **Trae（字节）**：6月举办 AI 创意编程大赛，持续拓展国内 AI IDE 市场
- **Claude Code**：年化收入接近关键里程碑，Anthropic 6月15日起为付费版 Claude 增加程序化调用专用额度，无需单独申请 API Key
- **Codex CLI**：OpenAI 持续推动 Codex 在企业场景落地，通过 Oracle 云承诺即可访问
