## 大模型板块

### Anthropic 估值 9650 亿冲刺 IPO，超越 OpenAI 成 AI 估值第一

Anthropic 于 6 月 1 日向 SEC 秘密提交 S-1 文件，正式启动 IPO 程序。最新 H 轮融资 650 亿美元，投后估值 **9650 亿美元**，三个月内从 3800 亿飙涨 154%，正式超越 OpenAI 的 8520 亿估值成为全球最贵 AI 公司。

支撑这个估值的 ARR 增长曲线堪称疯狂：2025 年底 90 亿美元 → 2026 年 2 月 140 亿 → 3 月 190 亿 → 4 月 300 亿 → 5 月突破 **440 亿美元**。Anthropic 计划 Q4 挂牌，高盛、摩根大通、摩根士丹利已入局。如果成功，这将是互联网泡沫以来最重量级的 AI IPO。

### MiniMax M3 开源发布：稀疏注意力 + 1M 上下文 + 全面能力

6 月 1 日，MiniMax 正式发布新一代旗舰模型 **M3**。核心变化是架构层彻底重写——自研 MiniMax Sparse Attention（MSA），1M 上下文下单 token 计算量仅为上代的 1/20。

能力上 M3 不偏科：SWE-Bench Pro 超过 GPT-5.5 和 Gemini 3.1 Pro，接近 Opus 4.7；多模态测试 OmniDocBench 超 Gemini 3.1 Pro；Claw-Eval Agent 框架评测拿下最高分。定位是「国内首个同时具备前沿 Coding + 1M 上下文 + 原生多模态的开源模型」。

定价更是杀疯了：Plus 版每月 **49 元（6 亿 token）**，Max 版 119 元（18 亿 token），Ultra 版 469 元（55 亿 token）。直接把大模型使用成本拉进「百元时代」。

### Qwen3.7-Plus：能看屏幕、能写代码、11 小时自动开发 App

6 月 2 日，阿里云发布 **Qwen3.7-Plus**，定位是「一个模型能看、能想、能写代码、能行动」的多模态 Agent 模型。屏幕理解基准 ScreenSpot Pro 得分 **79.0**，跑赢 GPT-5.4（67.4）和 Gemini 3.1 Pro（68.1）。

最硬核的演示：基于 Qwen3.7-Plus 的 Hybrid-Agent 系统连续稳定运行 11 小时以上，自动完成英语单词学习 App 的完整开发闭环——生成 10000+ 行代码、1000+ 次 Agent 调用，覆盖需求文档、代码编写、部署测试全链路。还高保真复刻了 macOS 原生 Stocks 应用，接入了真实行情 API。

输入 $0.4/百万 token，输出 $1.6/百万 token。

### OpenAI 提交 S-1，GPT-5.6 或 6 月发布

OpenAI 于 6 月 8 日向 SEC 秘密提交 S-1 草案。Sam Altman 对员工表示预计「未来一年内」进行 IPO。同时有消息称 **GPT-5.6** 可能在 6 月发布，作为 GPT-5.5 的迭代版。5 月 28 日 GPT-5.5 Instant 刚更新了响应风格和质量。

## 智能体板块

### CB Insights 发布 AI Agent 六大趋势报告

美国风投数据机构 CB Insights 发布 69 页重磅报告《AI Agent 圣经》，几个核心数据：

- 2025 年营收最高的 **20 家 Agent 初创公司**，一半三年前不存在
- Cursor 年收入 5 亿美元（2022 年成立），Replit 1.5 亿美元
- AI Agent 投融资交易在 2025 年 Top 10 赛道中占据 **5 个席位**
- 82% 的企业表示未来 12 个月内会把 Agent 应用于客户支持

六大趋势：语音 AI 崛起、AI 并购潮、推理成本推高利润压力、Agentic 商业模型建立、数据护城河之战、Agent 监控工具成为必备。

报告的核心判断：**氛围编程（Vibe Coding）的夏天结束了**——推理模型的 Token 输出量增加了约 20 倍，成本压力迫使 Cursor 等公司限速涨价。

### AI Agent 平台格局：三分天下

2026 年 AI Agent 平台竞争已进入生态战阶段。市场格局三分天下：消费流量型（扣子 Coze、腾讯元器、百度文心）、企业级底座型（金智维 Ki-AgentS）、前沿探索型（Manus、Google Astra、OpenAI Operator）。选型不再是挑工具，而是选技术路径和生态伙伴。

## AI 编程板块

### Claude 计费明日大改：交互与程序化「分家」

**这是这周最直接影响开发者的新闻。** 明天（6 月 15 日），Anthropic 将正式实施 Claude 订阅方案调整：**交互使用**（Claude.ai 聊天、交互式 Claude Code、Claude Cowork）与**程序化使用**（Agent SDK、claude -p、Claude Code GitHub Actions、基于 Agent SDK 的第三方应用）切割为两个独立额度池。

起因？Claude Agent SDK 被 OpenClaw 和 Conductor 等第三方工具大量调用，订阅额度迅速耗尽——一个 OpenClaw 用户跑自动化脚本，可能几个小时就吃掉一个月的聊天额度。

新制下，每个付费方案（Pro/Max/Team/Enterprise）都会获得单独的月度程序化额度，用完后按 API 费率计费。重度 claude -p 用户和 OpenClaw 用户需要特别关注——之前相当于享受数百美元 API 价值的订阅额度，之后会被框在一个固定池子里。

### AI 编程工具 2026：Cursor 体验最佳，Copilot 最稳

2026 年 AI 编程工具市场已从「代码补全」进化到「任务自治」。Cursor 3 凭 Glass 界面和云端虚拟机，月活突破 500 万；Claude Code 在 SWE-bench 登顶 80.8%，长任务自主执行能力领先；GitHub Copilot 开放 Free 计划，靠微软生态守住企业阵地；Windsurf 以免费策略抢夺个人开发者。

不过利润压力正在渗透——推理成本飙升导致几乎所有工具都在涨价或限速，AI 编程的「烧钱换增长」模式不可持续了。
