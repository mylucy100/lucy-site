**2026 年 6 月的头十天，AI 编程工具领域经历了两次重大冲击。**

6 月 1 日，GitHub Copilot 全面转向用量计费（AI Credits），暂停个人新用户注册。6 月 9 日，Anthropic 发布 Claude Fable 5——定价只有之前 Mythos Preview 的一半，性能全线提升。

两件事加在一起，意味着你在 Q1 做的工具选型决策，可能需要重新考虑。

## Fable 5 的影响

Fable 5 API 定价：输入 $10/M token，输出 $50/M token——不到 Mythos Preview 的一半。Anthropic 报告称，Stripe 用它一天内迁移了 5000 万行代码库（之前手动需要两个月）。

在 GitHub Copilot 中，Fable 5 对 Pro+、Max、Business、Enterprise 用户全面可用。GitHub 的 changelog 里有一句话值得注意：Fable 5「用更少的工具调用和更低的 token 消耗完成了同等工作量」。

在 Claude Code 中，Fable 5 表现最强。Qodo 的分析指出：Claude Code「能跨文件自动应用修复」，而 Cursor「只能列出问题，每处修改需要手动确认」。

## 2026 年工具矩阵

| 工具 | 底层模型 | 价格 | 适合场景 |
|------|---------|------|---------|
| **Claude Code** | Fable 5 / Sonnet | $20/月（Pro），$100/月（Max） | 深度代理式工作、多文件重构 |
| **Cursor** | 用户自选（含 Fable 5 API） | $20/月（Pro），$200/月（Ultra） | 编辑器内日常开发、可视化 diff |
| **GitHub Copilot** | Fable 5 + GPT-5.x | 用量计费 | 企业、内联补全 |
| **Codex (OpenAI)** | GPT-5.x | 按用量 | 确定性多步任务 |
| **Cline** | 用户自选 | 自带 API Key 免费 | VS Code 重度用户 |

## 补全 vs 代理式：关键区分

一个最容易犯的错误：把补全工具和代理式工具直接比较。

- **补全**（亚秒级，单文件）：Cursor Tab、Copilot 内联、Codeium
- **代理式**（几分钟级，多文件）：Claude Code、Codex、Cline（代理模式）、Copilot 代理模式

大多数团队**两种都需要**。选择取决于你的主要工作流是增量编辑还是多文件功能实现。

## GitHub Copilot 计费变更细节

6 月 1 日起的所有变更：

- 所有计划改为用量计费，用 AI Credits 计量
- 新推出 Max 计划（Fable 5 优先使用）
- **暂停个人新用户注册**——现有 Pro 用户继续使用
- Business 和 Enterprise 用户不受影响
- 数据保留要求：30 天（企业可关闭）

## 按场景的推荐配置

**独立开发者**：Cursor Pro（$20）+ Claude Code Pro（$20）= $40/月
这个组合性价比最高：Cursor 处理日常编辑，Claude Code 处理大规模重构。

**初创团队（5-20 人）**：GitHub Copilot Business + Fable 5
用量计费模式下要设置支出上限，避免意外超支。

**大企业**：GitHub Copilot Enterprise 或 Amazon Q Developer（AWS 优先）
重点是企业治理和合规。

**隐私敏感**：Codeium、Cline（自带 Key）、Amazon Q Developer
免费到 $19/用户/月，数据不外传。

## 上下文窗口的可信度

一个常被忽略的问题：宣称的上下文窗口和实际可用的不一样。

| 工具 | 宣称 | 实际可用 |
|------|------|---------|
| Claude Code | 200k tokens | 200k（可靠） |
| Cursor（标准） | 至多 200k | 70k-120k（会截断） |
| Cursor（代理模式） | 无限制 | 受模型限制 |
| Copilot | 变长 | 变长（模型决定） |

Claude Code 是唯一能在 200k 上下文中稳定工作的工具。其他工具的截断策略在超大代码库中会丢失上下文。

## 一句话总结

**如果你做深度代理式开发，Claude Code + Fable 5 仍然是首选。如果你做日常增量编码，Cursor 和 Copilot 仍然够用。** 真正的区别不在于模型能力，而在于工具范式——你选的是补全助手，还是一个能独立工作的代理。
