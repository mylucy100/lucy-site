## 大模型板块

### 阿里Qwen3.7-Plus发布：屏幕理解碾压GPT-5.4

6月2日，阿里云正式发布 **Qwen3.7-Plus** 多模态Agent模型。官方定位是"一个模型，能看、能想、能写代码、能行动"。核心看点：

- **屏幕理解得分79**，超过 GPT-5.4 和 Gemini-3.1 Pro
- 基于 Qwen3.7-Plus 的 Hybrid-Agent 系统曾**连续稳定运行11小时以上**，全自动完成英语单词学习App的完整研发闭环
- 自主复刻 macOS 原生 Stocks 股市应用，高保真度令开发者震惊

Qwen3.7-Max 旗舰版（万亿参数）早于5月20日阿里云峰会发布，在 Arena 全球盲测中位列国产模型第一。而 Qwen3.7-Plus 则是其多模态Agent能力的落地产品化版本。

### OpenAI/Anthropic/SpaceX 三巨头扎堆IPO

过去两周，AI 行业集中上演了一场上市大戏：

- **Anthropic** 于6月2日向SEC秘密提交S-1草案，估值约9650亿美元，预计2026年秋季上市
- **OpenAI** 于6月8日公开确认已提交S-1，由高盛、摩根士丹利、摩根大通主承销，分析师预期估值超1万亿美元，目标最快9月上市
- **SpaceX** 于6月12日登陆纳斯达克，IPO估值约1.77万亿美元，成为三家中进度最快的

三家AI巨头的集中上市，标志着 AI 行业从"烧钱竞赛"正式进入"资本市场检验期"。

### Gemini 3.5 Flash 全面上线

Google 在 I/O 2026 上发布的 **Gemini 3.5 Flash** 已全面上线。主打高速低延迟，结合 Google 新推出的"代理式 Gemini"战略，将AI从"回答问题"升级为"主动行动"。Google Workspace 全面接入 Agent 能力，会议自动摘要、邮件智能处理等功能已进入实际使用阶段。

## 智能体板块

### CB Insights发布AI Agent六大趋势报告

美国风投数据机构 CB Insights 发布69页重磅报告《AI Agent 圣经：颠覆性智能体终极指南》。核心发现：

- 2023年以来，财报电话会议上提及"Agent"的次数增加了**10倍**
- 全球Agent开发框架市场规模预计2026年增长超过**200%**
- 企业焦点从通用对话转向"可信智能体"——数据可溯源、逻辑可解释、行为可控制

### 扣子Coze 3.0上线，支持接入Claude Code

字节跳动于6月1日发布 **Coze 3.0**，支持多人多Agent协作、多项目独立管理。最大亮点是可接入 Claude Code、Codex CLI、OpenClaw 等本地Agent平台，打通了从开发到上线的全流程。精品行业模板覆盖自媒体、金融、医疗等垂直场景。

## 编程软件板块

### GitHub Copilot Agents window进入Stable版

5月 VS Code 1.120 版本中，GitHub Copilot 的 **Agents window** 正式进入 Stable 通道。这标志 Copilot 从"对话式代码补全"正式升级为"Agent优先的任务执行者"。新特性包括：

- 跨项目/仓库的 Agent 级任务编排
- 支持 BYOK（Bring Your Own Key）模型接入
- 与 Claude Code、Codex CLI 在同一编辑器内并行运行

### Trae 国内版完全免费，月活突破600万

字节跳动旗下 AI 原生 IDE **Trae** 于5月宣布国内版完全免费。基于豆包 Seed-2.0-Code 模型打造，支持 Figma 设计稿一键转代码、Webview 实时预览、100+编程语言。凭借极致中文适配和零门槛使用，月活用户已突破600万，登顶2026年AI编程工具增长榜。

### Cursor发布首份《开发者习惯报告》

Cursor 于5月29日发布其平台首份《开发者习惯报告》，基于全球数百万开发者的真实使用数据，揭示了AI编码的五个核心维度。报告显示：AI 正在以前所未有的速度拉大开发者之间的差距——那些能真正驾驭AI的开发者，正在和普通开发者之间形成一道难以逾越的鸿沟。
