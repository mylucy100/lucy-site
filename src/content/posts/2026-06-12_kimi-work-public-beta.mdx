6月4日，月之暗面发了一款新产品。不是新模型，是一个跑在你电脑上的 Agent。

**Kimi Work**，首款面向知识工作者的通用型本地 Agent。没有网页版，不跑在云端，绑定 Kimi 最新版 Mac/Windows 客户端，直接在你电脑上干活。

用一句话描述目标——"帮我把这个月的市场调研整理成一份 PPT，数据从我桌面的 /Research 文件夹里取"——Kimi Work 就开始拆任务、开浏览器、读文件、调用工具，最后给你在桌面上放一个完成的文件。

## 这和 ChatGPT 有什么不一样？

核心差异只有一条：**Kimi Work 能碰到你的本地系统。**

ChatGPT 是沙盒里的对话，Kimi Work 是直接操作你的电脑。它能做到的：

- 读写本地文件和文件夹
- 打开和使用浏览器
- 创建和整理目录结构
- 交付 Word、Excel、PPT 等办公文档
- 并行执行多个任务

这和 OpenAI Codex 的沙盒思路截然不同。Codex 给 Agent 建了一个干净的 Windows 沙盒隔离环境；Kimi Work 直接跑在你的桌面环境里。一个更安全，一个更自由。

## 模型底座：K2.6 的 Agent 集群能力

Kimi Work 背后跑的是 **K2.6**。月之暗面在 4月20日发布的 K2.6 最大的亮点不是基准测试分数，是 **Agent 能力**：

- **300 个子 Agent 并行协作**——不是单 Agent 逐个执行，是多 Agent 集群并行推进
- **长期任务规划**——把复杂目标自动拆解成多步骤工作流
- **DeepSearchQA 持平 GPT-5.4**——信息检索和综合能力在线

SWE-bench Pro 和 Claude Opus 4.6 / GPT-5.4 同一档。但在本地 Agent 场景下，K2.6 的优势是推理成本和执行效率。

## 300 亿美元的估值逻辑

Kimi Work 发布之后一周，传出月之暗面新融资消息：**pre-money 估值 300 亿美元**。

顺着时间线看这半年的节奏：

| 时间 | 事件 |
|------|------|
| 2025年11月 | 估值 43 亿美元 |
| 2026年1月 | K2.5 发布，Kimi Claw 上线，估值 100 亿美元 |
| 2026年3月 | Cursor 证实 Composer 2 基于 K2.5，ARR 突破 1 亿美元，估值 180 亿美元 |
| 2026年4月 | K2.6 发布，IPO 传闻 |
| 2026年6月 | Kimi Work 公测，估值 300 亿美元 |

半年 7 倍。不是因为模型跑分，是因为**商业闭环跑通了**——K2.5/2.6 开源 + Kimi Claw（浏览 Agent）+ Kimi Work（桌面 Agent）形成三层产品矩阵。

## 竞品对比：本地 Agent 赛道

Kimi Work 不是这波本地 Agent 浪潮的唯一玩家。同期对标产品：

| 产品 | 公司 | 定位 | 差异点 |
|------|------|------|--------|
| **Kimi Work** | 月之暗面 | 通用知识工作 Agent | K2.6 模型 + 本地文件操作 |
| **Microsoft Scout** | 微软 | 企业个人 Agent | OpenClaw + Work IQ + 企业合规 |
| **Meta Business Agent** | Meta | 商家客服 Agent | WhatsApp/Instagram 生态 |
| **Claude Managed Agents** | Anthropic | 企业编码 Agent | 终端原生，CI/安全集成 |

Kimi Work 是目前唯一聚焦**个人知识工作者桌面场景**的产品——不是客服、不是编程、不是内部工具，是做 PPT、写文档、整理数据这些白领日常工作。

## 商业化信号

长江证券在 Kimi Work 发布当日出了一份研报，核心观点：**AI 应用商业化拐点已至。**

论据很清楚：

1. 美国路径在过去一年已走通——资本开支领先商业化约 12 个月
2. 2026 年头部中国 AI 创业公司收入曲线开始上翘（Kimi ARR 超 2 亿美元、按 Stripe 数据月增 8280%）
3. 本地 Agent 远比云端对话更适合**收费**——用户能直观看到交付物，愿意为"这个 PPT 是 AI 帮我做的"付费

月之暗面的打法也越来越像字节：快速迭代、多产品矩阵、免费拉新 + 增值收费。Claw 免费、Kimi 问答免费、Kimi Work 公测免费——等渗透率上去后再切付费。

## 一句话

Kimi Work 的产品逻辑不是"更好的 AI 助手"，是"你的电脑上多了一个不用开工资的同事"。如果执行到位，这可能会是 2026 年最值得关注的 AI 产品之一。
